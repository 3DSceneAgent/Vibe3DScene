**修改文件**: `[web/src/components/MarkdownMessage.tsx](web/src/components/MarkdownMessage.tsx)`

## 问题3：修复 Blender 插件注册错误

### 3.1 问题分析

**错误信息**:

```
RuntimeError: Error: register_class(...): already registered as a subclass 'BLENDERMCPV_ChatMessage'
```

**根本原因**: `BLENDERMCPV_UL_ChatHistory` 类在两个文件中都定义了：

- `[addon/blender_mcpv_addon/properties.py](addon/blender_mcpv_addon/properties.py)`: 第14-19行
- `[addon/blender_mcpv_addon/ui.py](addon/blender_mcpv_addon/ui.py)`: 第7-13行

导致 Blender 尝试重复注册同一个类。

### 3.2 解决方案

**修改文件**: `[addon/blender_mcpv_addon/properties.py](addon/blender_mcpv_addon/properties.py)`

- **删除** `BLENDERMCPV_UL_ChatHistory` 类定义（第14-19行）
- 在 `register()` 中移除 `bpy.utils.register_class(BLENDERMCPV_UL_ChatHistory)`
- 在 `unregister()` 中移除 `bpy.utils.unregister_class(BLENDERMCPV_UL_ChatHistory)`

**原因**: `ui.py` 中已经有完整的 `BLENDERMCPV_UL_ChatHistory` 实现，`properties.py` 中的是重复定义。

**修改文件**: `[addon/blender_mcpv_addon/__init__.py](addon/blender_mcpv_addon/__init__.py)`

- 检查注册顺序，确保 `properties.register()` 在 `ui.register()` 之前调用
- 当前顺序已正确（第37-39行）

### 3.3 验证

- 在 Blender 中卸载旧版插件
- 重启 Blender
- 重新安装修复后的插件
- 确认无注册错误
